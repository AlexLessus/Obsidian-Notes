| <br>1. **Representación de Datos (Data Representation)**:                  | El corazón del aprendizaje de máquinas consiste en transformar los datos para que sean más legibles o útiles para una tarea específica. El aprendizaje profundo se caracteriza por extraer representaciones útiles de manera progresiva y jerárquica a través de múltiples capas sucesivas                                                                          | Forma en que la información del mundo real (imágenes, texto, audio o tablas) se codifica numéricamente para que una red neuronal pueda procesarla, típicamente mediante **tensores** (vectores, matrices o arreglos multidimensionales).                                                      | Es la forma en que se codifican los datos de entrada (texto, imágenes, audio, etc.) como estructuras numéricas —vectores, matrices o tensores— que una red neuronal puede procesar.                                                                                                                                                                                                                                                                                                                                | Transformar información o datos para que una red neuronal pueda procesarlos.                                        |
| 2. **Capas (Layers**):                                                     | Es el bloque de construcción fundamental de una red neuronal. Cada capa actúa como un filtro que toma datos de entrada y entrega una nueva representación de los mismos, logrando una destilación progresiva de la información.                                                                                                                                     | Bloques constructivos fundamentales de una red neuronal compuestos por un conjunto de neuronas (o nodos). Cada capa recibe una entrada, realiza transformaciones matemáticas (combinaciones lineales seguidas de activaciones) y produce una salida que sirve de entrada a la siguiente capa. | Son las unidades estructurales de una red neuronal. Cada capa recibe una entrada, le aplica una transformación (típicamente una combinación lineal seguida de una función de activación) y produce una salida que alimenta a la siguiente capa. Existen distintos tipos: capas densas (fully connected), convolucionales, recurrentes, de atención, etc.                                                                                                                                                           | Son los bloques que forman una red neuronal, cada capa recibe una entrada, realiza algo y produce una salida.       |
| <br>3. **Profundidad (Depth)**                                             | Se define por la longitud o cantidad de capas en la cadena de funciones que componen el modelo ($f(x) = f^{(3)}(f^{(2)}(f^{(1)}(x)))$). De esta estructura jerárquica de funciones proviene directamente el nombre de Deep Learning                                                                                                                                 | Número total de capas ocultas (o transformaciones secuenciales) que componen la arquitectura de una red. Es la característica que define al _Deep Learning_, permitiendo extraer representaciones jerárquicas que van desde patrones simples hasta conceptos altamente abstractos.            | Se refiere al número de capas que tiene una red neuronal entre la entrada y la salida. Una red "profunda" (deep) tiene muchas capas apiladas, lo que le permite aprender representaciones cada vez más abstractas y jerárquicas de los datos a medida que la información avanza por la red.                                                                                                                                                                                                                        | El numero de capas de una red neuronal.                                                                             |
| <br>4. **Pesos o Parámetros Entrenables (Weights / Trainable Parameters)** | Son tensores (matrices o vectores) que controlan la transformación geométrica realizada por cada capa. En estos parámetros numéricos reside propiamente el "conocimiento" que el modelo adquiere a partir de los datos                                                                                                                                              | Coeficientes numéricos internos ($W$) y sesgos ($b$) que escalan y desplazan las señales entre neuronas. Representan el «conocimiento» acumulado del modelo y se ajustan iterativamente durante el entrenamiento.                                                                             | Son los valores numéricos internos de la red (junto con los sesgos o _biases_) que se ajustan durante el entrenamiento. Determinan cómo se transforma la información en cada capa. "Entrenar" un modelo consiste precisamente en encontrar los valores de estos parámetros que minimizan el error del modelo.                                                                                                                                                                                                      | Son valores o parámetros que se ajustan durante el entrenamiento, en estos es donde se encuentra el "conocimiento". |
| <br>5. **Función de Pérdida / Costo (Loss / Objective / Cost Function)**:  | Es la medida matemática que cuantifica qué tan alejada está la predicción actual del modelo con respecto al valor real esperado (_target_). Produce un puntaje numérico (_loss score_) que sirve como la señal de retroalimentación esencial para guiar el aprendizaje.                                                                                             | Métrica matemática que cuantifica el error o discrepancia entre la predicción generada por el modelo ($\hat{y}$) y el valor real esperado ($y$). Proporciona la señal cuantitativa de qué tan bien o mal se está desempeñando la red.                                                         | Es una función matemática que mide qué tan lejos está la predicción del modelo del valor real (ground truth). Cuanto mayor sea la pérdida, peor es el desempeño del modelo. El objetivo del entrenamiento es minimizar esta función.                                                                                                                                                                                                                                                                               | Es la métrica que mide el error de la predicción.                                                                   |
| <br>6. **Optimizador (Optimizer)**:                                        | Es el motor que determina cómo se van a actualizar los pesos del modelo a partir del puntaje de la función de pérdida. Implementa variantes del Descenso de Gradiente Estocástico (SGD) para ajustar gradualmente los parámetros en la dirección que minimice la pérdida.                                                                                           | Algoritmo encargado de actualizar los pesos y sesgos del modelo en función del gradiente calculado de la función de pérdida (por ejemplo, SGD, Adam, RMSprop), con el objetivo de converger hacia el mínimo global o local del error.                                                         | Es el algoritmo que ajusta los pesos de la red para minimizar la función de pérdida, usando los gradientes calculados por retropropagación. Ejemplos: SGD (descenso de gradiente estocástico), Adam, RMSprop. El optimizador determina el tamaño y dirección de los pasos que se dan en cada actualización de parámetros (a menudo controlado por la _tasa de aprendizaje_ o _learning rate_).                                                                                                                     | Es el algoritmo que se encarga de ajustar los pesos para minimizar la perdida.                                      |
| <br>7. **Regla de la Cadena y Retropropagación (Backpropagation)**:        | El algoritmo que permite calcular de manera exacta el gradiente de la función de pérdida respecto a cada peso de la red neuronal. Consiste en aplicar la regla de la cadena matemática de derivación sobre un grafo de computación, viajando en sentido inverso (desde la última capa hacia la primera) para distribuir la contribución al error de cada parámetro. | Algoritmo central de entrenamiento que calcula eficientemente los gradientes de la función de pérdida respecto a cada parámetro de la red. Aplica de forma recursiva la **regla de la cadena** del cálculo multivariable desde la capa de salida hacia atrás (hacia la entrada).              | La retropropagación es el algoritmo que calcula cómo cada peso de la red contribuyó al error final, para poder actualizarlo. Se basa en la **regla de la cadena** del cálculo diferencial: como la red es una composición de funciones (capa tras capa), la derivada de la pérdida respecto a un peso en una capa temprana se calcula multiplicando las derivadas parciales de todas las capas posteriores hasta esa capa. Así, el error se "propaga hacia atrás" desde la salida hasta la entrada, capa por capa. | El algoritmo que calcula cómo cada peso influye en el error final para poder ajustarlo.                             |
| <br>8. **Funciones de Activación (Activation Functions)**:                 | Operaciones no lineales aplicadas después de una transformación lineal en cada capa (como _ReLU_ o _Sigmoid_). Son críticas para otorgarle a la red la capacidad de mapear relaciones complejas y acceder a espacios de hipótesis no lineales que no son separables con métodos sencillos.                                                                          | Transformaciones no lineales aplicadas a la salida de cada neurona (como ReLU, Sigmoide o Tanh). Sin ellas, la concatenación de capas colapsaría en una simple operación lineal, impidiendo que la red aprenda relaciones complejas.                                                          | Son funciones no lineales que se aplican a la salida de cada neurona o capa. Sin ellas, una red neuronal —sin importar cuántas capas tenga— equivaldría matemáticamente a una simple transformación lineal. Introducen no linealidad, permitiendo que la red aprenda patrones complejos. Ejemplos: ReLU, sigmoide, tanh, softmax (esta última usada típicamente en la capa de salida para clasificación).                                                                                                          | Operaciones no lineales que le dan la capacidad de mapear relaciones complejas y no sea una simple operación lineal |
