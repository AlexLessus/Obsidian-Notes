#IoT 

Al hacer un sistema, importante saber el protocolo que utiliza

## Elementos de un dispositivo IoT
Objeto físico - Proceso o entorno real
Percepción - Variable o estado medible
Identidad - Dispositivo distinguible
Comunicación - Intercambio con otro sistema
Datos - Procesamiento o almacenamiento
Utilidad - Decisión, alerta o actuación
