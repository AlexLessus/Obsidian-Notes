# 1. Conceptos centrales del tema

Este primer prompt sirve para que NotebookLM no te dé un resumen superficial, sino el mapa mental del tema.

```
Basándote en TODAS las fuentes de este cuaderno —artículos, papers, vídeos, guías, PDFs y materiales sobre memoria, sueño, atención, repetición espaciada, active recall y neuroaprendizaje— identifica los 5 conceptos centrales para aprender más rápido según la neurociencia.

No quiero un resumen de cada fuente.

Quiero las IDEAS BASE que sostienen todo el tema: los principios que explican cómo aprende realmente el cerebro y que una persona experta daría por sentados, pero que un principiante normalmente no sabría conectar.

Para cada concepto central:

1. Nómbralo con una frase clara.
2. Explícalo de forma sencilla, sin tecnicismos innecesarios.
3. Explica por qué es importante para aprender mejor.
4. Indica con qué otros conceptos del cuaderno se relaciona.
5. Cita al menos 2 fuentes del cuaderno que lo respalden.
6. Señala el error típico que comete alguien que no entiende bien este concepto.
7. Da un ejemplo práctico de cómo aplicarlo al estudiar, trabajar o aprender una habilidad nueva.

Prioriza conceptos que aparezcan repetidos en varias fuentes y que ayuden a construir un mapa mental completo del tema.
```

# 2. Qué tendría que entender para enseñarlo

Este prompt sirve para pasar de “reconozco el concepto” a “puedo explicarlo desde cero”.

```
¿Qué tendría que entender de verdad de este material para poder enseñárselo a una persona que no sabe nada sobre neurociencia ni aprendizaje?

No quiero una explicación superficial. Quiero que identifiques las ideas clave que tendría que dominar para explicarlo con claridad desde cero.

Para cada idea, dime:

1. Qué debo entender realmente.
2. Qué suele confundirse o explicarse mal.
3. Qué ejemplo simple podría usar.
4. Qué señal indicaría que aún no lo he entendido bien.
5. Qué fuentes del cuaderno debería revisar para profundizar.

Prioriza lo más importante para enseñar el tema de forma clara, práctica y conectada.
```

# 3. Preguntas que exponen si solo has memorizado

Este prompt convierte el cuaderno en un test de comprensión profunda.

```
Genera 10 preguntas que expongan si alguien entiende profundamente cómo aprender más rápido según la neurociencia o si solo ha memorizado consejos sueltos.

Las preguntas deben:

1. Requerir razonamiento, no memoria.
2. Conectar conceptos de varias fuentes del cuaderno.
3. Incluir situaciones reales de estudio o trabajo.
4. Mostrar casos donde un consejo típico pueda fallar.
5. Estar ordenadas de menor a mayor dificultad.
```

# 4. Corrige mi respuesta como un tutor

Este prompt sirve para responder una pregunta, fallar, y que NotebookLM te diga exactamente dónde estás flojo.

```
Voy a responder a esta pregunta. Evalúa mi respuesta con dureza, pero de forma útil.

Pregunta: Un universitario memoriza con flashcards 100 fórmulas de física. Respeta los intervalos de repetición espaciada, duerme bien y las recuerda todas, pero al resolver un problema real no sabe qué fórmula aplicar. ¿Por qué fracasa el aprendizaje si no ha construido una red de significado?

Mi respuesta: El problema es que ha memorizado las fórmulas, pero no ha practicado suficientes ejercicios reales.

Dime:

1. Qué parte de mi respuesta está bien.
2. Qué parte es superficial.
3. Qué concepto del cuaderno no he entendido del todo.
4. Qué fuentes concretas debería revisar.
5. Cómo habría respondido alguien que domina este tema.
```

# 5. Crea una sesión de estudio de 90 minutos

Este prompt convierte todo lo trabajado en una sesión guiada y accionable.

```
Con todo lo que hemos trabajado en esta conversación y todas las fuentes de este cuaderno, créame una sesión de estudio de 90 minutos para entender mejor cómo aprender más rápido según la neurociencia.

Quiero que dividas la sesión por bloques de tiempo e incluyas:

1. Qué debo estudiar en cada bloque.
2. Qué pregunta debo responder.
3. Qué fuente debería revisar si me atasco.
4. Qué resultado debería tener al final de cada parte.
5. Qué debo hacer en los últimos 10 minutos para cerrar bien la sesión.
```

# 6. Kit de repaso para consolidar lo aprendido

Este prompt sirve para terminar con material práctico de repaso, sin tener que volver a leer todo el cuaderno desde cero.

```
Con todo lo que hemos trabajado en esta conversación y todas las fuentes del cuaderno, créame un kit de repaso para consolidar este tema.

Quiero que incluya:

1. Una hoja de estudio de una página con las ideas clave.
2. Una tabla con los errores típicos y cómo corregirlos.
3. Diez preguntas de repaso ordenadas por dificultad.
4. Un plan de repaso para los próximos 7 días.
5. Las fuentes concretas que debería revisar si me atasco.

Hazlo práctico, claro y pensado para repasar sin volver a leer todo el cuaderno desde cero.
```

# Extra 1. Adaptar el método a cualquier tema

Puedes usar este prompt si quieres aplicar el mismo sistema a otro cuaderno.

```
Quiero usar este cuaderno para aprender [TEMA].

No quiero que me resumas las fuentes.

Quiero que me ayudes a construir un sistema de aprendizaje completo.

Primero, identifica las ideas centrales del tema.
Después, dime qué tendría que entender para poder explicárselo a alguien desde cero.
Luego, genera preguntas que detecten si solo he memorizado o si realmente entiendo.
Y finalmente, proponme una sesión de estudio de 90 minutos para trabajarlo de forma activa.

Usa únicamente las fuentes de este cuaderno y cita las fuentes concretas cuando sea necesario.
```

# Extra 3. Técnica Feynman con corrección

Este prompt sirve para explicar un concepto con tus palabras y recibir feedback.

```
Voy a intentar explicar este concepto como si se lo contara a alguien que no sabe nada del tema.

Concepto: [ESCRIBE AQUÍ EL CONCEPTO]

Mi explicación:
[PEGA AQUÍ TU EXPLICACIÓN]

Evalúa mi explicación.

Dime:

1. Qué parte está clara.
2. Qué parte está incompleta.
3. Qué he simplificado demasiado.
4. Qué error conceptual estoy cometiendo.
5. Qué analogía o ejemplo podría usar para explicarlo mejor.
6. Qué fuentes del cuaderno debería revisar para mejorar mi explicación.
```

# Cómo usar estos prompts

1. Crea un cuaderno en NotebookLM sobre el tema que quieras aprender.
2. Sube varias fuentes: artículos, vídeos, PDFs, papers, apuntes o transcripciones.
3. Empieza por el prompt de conceptos centrales.
4. Sigue con el prompt para enseñar el tema.
5. Genera preguntas difíciles.
6. Respóndelas sin mirar las fuentes.
7. Pide corrección.
8. Crea una sesión de estudio de 90 minutos.
9. Termina con un kit de repaso para consolidarlo.

La clave no es que NotebookLM te dé respuestas.

La clave es usarlo para hacer mejores preguntas, detectar tus errores y estudiar de forma más activa.
